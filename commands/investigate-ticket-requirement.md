When receiving a YouTrack ticket number:

1. Use YouTrack MCP to fetch and read the ticket description including attachments.
2. Make a brief report including:
   - Problem need to be addressed.
   - App/Repo to be working on. (All related repositories are at the same level with .claude folder)
3. Make a plan how you will update to fix this issue.
4. If changes are made, patch version in package.json to a minor version. (eg. 3.2.1 to 3.2.2)
