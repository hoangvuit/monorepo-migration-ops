1. Use repo `central-spa`.
2. Check out the `main` branch and pull for latest code.
3. Switch to a new branch based on `main` (append timestamp to branch name).
4. Run `yarn update` to generate new `yarn.lock` file with updated packages (if any).
5. Commit changes.
6. Run `yarn version --patch` to patch the repo to a minor version.
7. Push to remote.
